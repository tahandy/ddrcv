      Capture behavior & filenames
      
Screenshots only saves when the results screen ends or after ten seconds. Enable Capture results and Discord publishing for automatic posts.

      
With Screenshots only off, scores post as soon as confirmed. Names that confirm later update the same Discord message.

      
Filenames use UTC timestamps and a unique suffix. Player names are included only when enabled and successfully parsed.

      
Allowing repeats saves a new result on each replay and can post again. One continuous results screen still produces one result. Save your profile to keep this preference.

      
Applying settings restarts confirmation for a result still being read. Saved results stay unchanged.
